Recherche web

Donne à l'IA la capacité de chercher sur internet et de lire des pages. DuckDuckGo fonctionne sans configuration ni clé.

DuckDuckGo ne demande aucune clé. Le fournisseur externe attend une API compatible Tavily.

Endpoint qui accepte { query, max_results } et renvoie results[].

Stockée chiffrée, comme les clés de modèles.

Lance une requête réelle pour vérifier la configuration.

Serveurs MCP

Branchez des outils externes : accès fichiers, git avancé, bases de données, navigateur, services web. Chaque serveur est un processus lancé par Cerveau, piloté en JSON-RPC sur son entrée/sortie standard.

Certains serveurs exigent une clé, passée en variable d'environnement : BRAVE_API_KEY pour la recherche, GITHUB_TOKEN pour GitHub. Séparez plusieurs variables par une espace.
